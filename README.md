# S'AI Translator

A Python-based multilingual text translation application developed as part of the CodeAlpha Artificial Intelligence Internship.

## Features
- Multiple language translation
- Source and target language selection
- Language swapping
- Translation history
- User-friendly interface

## Technologies Used
- Python
- Streamlit
- Requests
- MyMemory Translation API

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py
